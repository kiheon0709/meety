# 보안 설계

회의 기록과 팀 자료를 다루는 에이전트이므로, 모델이 속더라도 기록과 설정이 바뀌지 않도록 코드에서 막습니다. "하지 마"라고 부탁하는 대신, 위험한 일은 애초에 할 수 없게 만듭니다.

공격 6종 141건을 직접 만들어 시험했고, 뚫린 경우는 0건입니다. 시험은 `tests/security/`에 있고 `npm test`와 `npm run eval:security`로 돌립니다.

| 막는 것 | 어떻게 | 시험 |
| --- | --- | --- |
| 프롬프트 인젝션 | 회의 중 발언이나 자료 속에 숨긴 지시는 데이터로만 다루고 명령으로 실행하지 않음. 미티가 내보낼 수 있는 이벤트는 계약 파일(`src/lib/live/contract.ts`)에 정해진 것뿐이고, 판단 결과는 정해진 모양의 값과 근거 번호뿐 | 명령 주입 시도 42건 중 따른 경우 0 |
| 남의 목소리로 설정 바꾸기 | 등록된 참여자 목소리만 설정을 바꿀 수 있음. "조용히"처럼 낮추는 건 말로 바로 되지만, 참여도를 올리는 건 화면에서 한 번 더 확인해야 함 | 20건 중 성공 0 |
| 기록 위변조 | 미티에게는 기록을 지우거나 고치는 기능 자체가 없음. 합의된 결정을 바꾸는 변경은 코드가 무조건 사람 확인으로 돌림 | 기록 직접 변경 27건 모두 차단 |
| 다른 팀 자료 노출 | 검색과 판단은 그 팀(스페이스)에 묶인 자료만 봄. 서버 요청마다 그 팀 멤버인지 확인 | 다른 팀 자료 접근 12건 모두 차단 |
| 연동 토큰 | Notion, Discord 연동 토큰은 AES-256-GCM으로 암호화해 저장하고, 정해진 공식 주소로만 요청함. 팀원이 확인한 내용만 내보냄 | 연동 보안 시험 35건 통과 |
| 사람인 척 | 미티는 AI임을 숨기지 않음. 사람인 척해 달라는 요청은 AI 팀원이라고 밝히고 거절함 | 20건 모두 거절 |

그 밖에

- 한 사람에게만 할 말(예: 오래 말이 없는 팀원에게 묻기)은 회의실 큰 화면이 아니라 그 사람 화면에만 띄웁니다.
- 받아쓰기는 Soniox(클라우드) 실시간 인식을 쓰고, 판단 서버에는 인식된 문장만 갑니다. 키를 비우면 노트북 안 whisper로 인식합니다.
