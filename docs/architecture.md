# 시스템 구조와 실시간 음성 파이프라인

## 구조

```
회의실 기기                 음성 처리 서버 (Python)              에이전트 서버 (TypeScript)          미티 화면
마이크 ──소리──▶  발화 종료 감지 (Silero VAD + Smart Turn v3.2)  ──인식된 문장──▶  회의 상태 유지, 역할 판단,    ──▶  마스코트, 말하기 전 이유 카드,
브라우저, 회의실 TV   실시간 음성 인식 (Soniox, 노트북 안 whisper 선택)        말할 때 고르기                     근거 자료, 자막, 손든 항목,
각자 휴대폰 ◀─목소리─  화자 구분 (Resemblyzer)              ◀──응답 문장──  자료 검색 (파일, Notion, 웹)        개인 알림은 그 사람 화면에만
                    스트리밍 음성 합성 (Qwen3-TTS)                     (자세히는 brain-design.md)
                                                                       │
                                                                       └──▶ 연동: 팀원이 확인한 내용만 Notion, Discord로
```

- 발화 종료 감지, 화자 구분, 음성 합성은 노트북 안에서 돌고, 음성 인식은 Soniox 실시간 인식을 씁니다(키가 없으면 노트북 안 mlx-whisper).
- 에이전트 서버는 Next.js 앱 안에 있고, 판단은 Claude Haiku 5.5, 말할 문장과 검증은 Claude Sonnet 5.5가 맡습니다.
- 기록은 SQLite에 회의마다 쌓이고, 바뀐 결정은 지우지 않고 이력으로 남깁니다. 미티는 기록을 읽기만 합니다.
- 팀 자료는 올린 파일(md, txt, pdf, zip)과 Notion 페이지에서 뽑아 두고, 키워드 검색(BM25)과 노트북 안에서 도는 임베딩 모델을 함께 써서 찾습니다.

## 실시간 음성 파이프라인 최적화

사람이 말을 마친 순간부터 미티의 첫 음성까지 전 구간을 단계별로 재고 줄였습니다. 음성 인식, 판단, 음성 합성을 차례로 기다리지 않고 동시에 흐르도록 구성했습니다.

| 단계 | 바꾼 것 | 결과 |
| --- | --- | --- |
| 발화 종료 감지 | 일정 시간 침묵을 기다리지 않고, 말이 끝났는지 소리로 판단하는 Smart Turn v3.2(8MB, 노트북 안)를 적용 | 말 끝 → 음성 인식 확정 908ms → 552ms (Soniox 기준) |
| 스트리밍 음성 합성 | 오픈소스 한국어 음성 합성 5종을 직접 비교해 Qwen3-TTS 1.7B를 고르고, 문장을 조각으로 나눠 합성하며 바로 재생 | 첫 음성까지 725ms → 112ms |
| 2단계 응답 생성 | 빠른 모델(Haiku)이 첫 문장을, 정확한 모델(Sonnet)이 나머지를 이어서 만듦 | 말 끝 → 첫 응답 문장 2.22초 → 1.41초 |
| 발화 중 선행 판단 | 상대가 말하는 동안 확정된 앞부분으로 판단을 시작 | 음성 인식 확정 → 응답 시작 1.27초 → 0.43초, 지난 결정 확인은 0.4초 안에 시작 |
| 끼어들기 처리와 채움말 | 사람이 말을 시작하면 미티 음성을 즉시 멈추고, "음…" 같은 채움말은 미리 합성 | 음성 정지 0ms, 말 끝 → 채움말 0.3초 이내 |
| 운영 비용 | 판단을 정해진 때에만 부름 | 회의 1시간 판단 비용 약 0.5달러 (실제 회의 녹음 71분에서 0.61달러) |

## 사용한 것

- 웹과 에이전트 서버: Next.js 16, React 19, three.js, React Three Fiber, SQLite, Zod, Vitest
- 음성 처리 서버: FastAPI, Silero VAD, Smart Turn v3.2, Soniox, mlx-whisper, Resemblyzer, Qwen3-TTS(MLX), Supertonic(대비용)
- AI 모델: Anthropic Claude API (Claude Haiku 5.5, Claude Sonnet 5.5, 웹 검색 도구)
- 연동: Notion, Discord, MCP

비교표와 측정 조건은 [조사와 측정 기록](research.md)에 있습니다.
