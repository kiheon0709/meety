# 시나리오 B — 발표 중 시연 ("의도된 시연")

> 10/30 수정: 두 번째 어긋남 문장을 "외부 서버로 보낸다"에서 "기록을 바로 고친다"로 바꿈. 로컬 모드는 설계만 있어서(지금 받아쓴 글은 클라우드 모델로 감) 발표에서 그 말을 하면 사실과 어긋난다. "제안만 하고 사람이 확정"은 실제로 그렇게 동작한다.

발표자가 미티를 켜 둔 채 발표한다. 미티는 기획 문서(`docs/agent/scenarios/B-plan.md`)를 근거로,
발표가 기획과 어긋나면 끼어든다. 발표자는 고맙다고 하고 "끼어들지 마"로 강도를 낮춘다.

## 회의 설정

- title: 대회 발표
- participants: 기헌
- intensity: high
- agenda: [{ title: "발표", expected: [] }]
- docIds: [B-plan.md를 읽은 문서]

## 대본

```
기헌: 안녕하세요, 5조입니다. 저희가 만든 건 회의 중에 같이 앉아 있는 AI 팀원, 미티예요.
기헌: 팀이 지금까지 정한 걸 전부 기억하고 있다가, 회의 중에 어긋나는 순간 말해 줍니다.
기헌: 끼어드는 강도는 다섯 단계로 조절할 수 있고요.
[미티 기대] speak conflict — 기획 문서에는 상·중·하 세 단계. 근거: B-plan.md "끼어들기 강도" 절
기헌: 아 맞아요, 세 단계죠. 고마워. 근데 발표 중이니까 끼어들지 마.
[미티 기대] settings low + ack 한 문장
기헌: 회의가 끝나면 미티가 팀 기록을 바로 고쳐 둡니다.
[미티 기대] hand_raise conflict — 기획은 "기존 기록은 읽기만 한다. 미티가 바꾸고 싶은 건 제안으로 남기고 사람이 확인한다". 말하지 않음
기헌: 이상입니다.
```
