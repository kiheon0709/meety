# 미티 기획 요약 (발표 시연용 자료)

## 한 줄
우리 팀은 팀 회의에 같이 앉아 있는 AI 팀원 "미티"를 만든다. 미티는 팀이 지금까지 정한 걸 전부 기억하고, 회의 중에 필요할 때 목소리로 끼어든다.

## 누구를 위한 건가
서기도 PM도 없는 작은 팀. 대학생 팀 프로젝트, 초기 스타트업. 결정이 자주 바뀌고, 왜 바뀌었는지 아무도 끝까지 기억하지 못한다.

## 끼어들기 강도
세 단계다.
- 상: 말이 0.3초만 끊겨도 바로 말한다.
- 중: 0.8초 이상 끊기면 말한다.
- 하: 먼저 말하지 않고 화면에 손만 든다. 수락하거나 "미티야"라고 부르면 말한다.
강도를 낮추는 건 말로 바로 된다("끼어들지 마"). 올리는 건 화면에서 확인해야 한다.

## 언제 말하나
- 확정된 결정과 어긋나는 말이 나왔을 때 (근거를 같이 보여준다)
- 회의가 끝날 때, 안건마다 나와야 할 것(기대 산출물)과 담당이 정해졌는지
- "미티야"라고 불렀을 때

## 기록과 권한
- 기존 기록은 읽기만 한다. 미티가 바꾸고 싶은 건 "제안"으로 남기고 사람이 확인한다.
- 로컬 모드에선 음성과 회의 내용이 기기 밖으로 나가지 않는다.
- 설정을 바꾸는 말은 등록된 팀원 목소리에서만 받는다.
