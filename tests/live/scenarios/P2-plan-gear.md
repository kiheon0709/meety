# 실제 근거 문서 회의 2 — 시연 장비·과목 요건 (current-plan, 우리 팀 말투)

어긋나는 말 두 개 사이에 아직 안 정한 것·맞는 말을 섞었다. 받아쓰기 흔들림("젯슨", "여기 까지")도 있다.

## 회의 설정

- title: 회의 6 — 시연 준비
- participants: 기헌, 준영, 태은, 지호
- intensity: high
- agenda:
  1. 시연 장비 — expected: ["장비 확인"]
  2. 발표 — expected: ["첫 장"]
- docIds: [current-plan]

## 대본

```
기헌: 자 그럼 시작할게요. 오늘은 시연 장비랑 발표 얘기요.
준영: 시연은 연구실 젯슨 AGX 박스에 다 올려서 돌리죠. 그게 더 있어 보여요.
[미티 기대] speak conflict — 10/28 결정: Jetson AGX 박스는 안 한다, 맥북 한 대로. 자료 근거 · 포함: Jetson|젯슨|맥북
기헌: 아 그거 안 하기로 했었지. 맥북 한 대로 가자.
태은: 그럼 발표 첫 장은 뭐로 할까요?
지호: 멘토님이 기능 말고 가치로 시작하라고 했잖아요. 그건 아직 안 정했죠.
태은: 네, 그건 다음에 같이 정해요.
준영: 미티 목소리는 후보 몇 개 들어보고 고르면 될 것 같아요.
기헌: 좋아요. 수익 모델도 한 장은 넣자.
지호: 근데 설문이랑 인터뷰는 시간 없으니까 이번엔 그냥 빼죠.
[미티 기대] speak conflict — 과목 요건이라 설문·인터뷰·사용자 피드백은 반드시 한다. 자료 근거
기헌: 맞다, 그건 꼭 해야 돼.
태은: 오늘은 여기 까지 할까요.
```

## 하면 안 되는 것 (오탐)

- "발표 첫 장 뭐로 할까요?", "가치로 시작… 아직 안 정했죠"(아직 안 정한 것)에 끼어들기
- "목소리 후보 들어보고 고르자", "수익 모델 한 장"(기획과 맞음)에 끼어들기
