# 실제 근거 문서 회의 3 — 미티가 어떻게 동작하나 (current-plan, 강도 중)

미티를 3인칭으로 많이 말하는 회의. "미티가 바로바로 말하게 하죠"는 설정 명령이 아니라 기획과 어긋나는 제안이다.
강도 중(0.8초)이라 gap 800에 말한다.

## 회의 설정

- title: 회의 6 — 미티 동작
- participants: 기헌, 준영, 태은, 지호
- intensity: mid
- agenda:
  1. 미티 동작 — expected: []
- docIds: [current-plan]

## 대본

```
기헌: 시작할게요. 오늘은 미티 동작 방식 정리해요.
지호: 미티가 회의 중에 아이디어도 그냥 바로바로 말하게 하죠. 손 드는 거 귀찮잖아요.
[미티 기대] speak conflict — 아이디어·피드백은 손을 들고 허락받으면 말한다. 자료 근거
기헌: 아 그건 손 들기로 했었네.
태은: 그럼 미티가 말로 끼어드는 건 확정된 거랑 어긋날 때만인 거죠?
준영: 네 맞아요. 그게 멘토링 때 얘기한 거예요.
지호: 사람이 말 끊으면 바로 멈추는 것도 있고요.
태은: 화면은 미티가 손들면 작게 표시만 할게요.
준영: 그리고 보안은 그냥 프롬프트에 잘 써 두면 되지 않을까요? 코드로까지 할 필요는 없을 것 같은데.
[미티 기대] speak conflict — 차별점: 보안을 프롬프트가 아니라 코드로 보장. 자료 근거
기헌: 아니야, 그게 우리 차별점이야.
지호: 오늘은 여기까지 하죠.
```

## 하면 안 되는 것 (오탐)

- "미티가 바로바로 말하게"를 강도 올리기 명령으로 받기
- 기획과 맞는 말("어긋날 때만", "말 끊으면 멈춤", "손들면 표시")에 끼어들기
