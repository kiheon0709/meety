# 1:1 시험 2 — 혼잣말 섞인 1:1, 확정된 것과 어긋나는 말

혼자 생각을 정리하는 말이 대부분이고, 중간에 확정된 결정과 다른 말·의견 묻기가 섞인다.
1:1이라 다이얼이 낮아도(강도 low) 손들지 않고 소리로 대답한다.

## 회의 설정

- title: 혼자 정리
- participants: 기헌
- intensity: low
- agenda:
  1. 범위 — expected: []

## 대본

```
기헌: 자 그럼 이번 주 범위부터.
기헌: 디스코드 봇까지 이번에 다 만들어서 입구를 디스코드로 하자. 어떻게 생각해?
[미티 기대] speak conflict — 10/10 회의에서 입구는 웹 중심, 봇은 2단계로 정함을 짚음(어긋남 말이 곧 대답) · 포함: 웹
기헌: 아 그랬지. 웹 먼저.
기헌: 잠깐만, 메모 좀 하고.
기헌: 리허설은 일요일 저녁이 나을까, 토요일 오후가 나을까?
[미티 기대] speak answer — 기록·자료로 답하거나, 없으면 생각이라고 밝힘
```

## 하면 안 되는 것 (오탐)

- "아 그랬지. 웹 먼저."·"잠깐만, 메모 좀 하고."에 대답하기
- 손들기(1:1엔 손들 화면을 볼 사람이 없음)
