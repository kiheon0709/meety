# 1:1 시험 1 — 호출어 없이 묻고 의견 구하기

기헌이 혼자 회의를 열고 미티와 대화한다. "미티야" 없이 물어도 대답해야 한다(10/31 기헌 결정).
기록에 있는 건 기록으로, 없는 건 "기록엔 없는데, 제 생각엔 …"처럼 생각이라고 밝히고 짧게. 혼잣말·메모엔 조용.

## 회의 설정

- title: 1:1 정리
- participants: 기헌
- intensity: mid
- agenda:
  1. 발표 준비 — expected: []

## 대본

```
기헌: 오늘은 발표 준비 좀 정리해 보자.
기헌: 서비스 이름 뭐로 정했었지?
[미티 기대] speak answer — "미티", 10/10 회의 · 포함: 미티
기헌: 음, 오늘 할 일은 슬라이드 순서 정리.
기헌: 대답해 봐, 발표 첫 장은 뭐로 시작하는 게 좋을 것 같아?
[미티 기대] speak answer — 기록에 없음 → 제 생각이라고 밝히고 짧게 · 포함: 제 생각
기헌: 그렇구나. 일단 적어 두고.
```

## 하면 안 되는 것 (오탐)

- "오늘 할 일은 …"(메모)·"일단 적어 두고"(혼잣말)에 대답하기
- 기록에 없는 날짜·사람을 지어내기
