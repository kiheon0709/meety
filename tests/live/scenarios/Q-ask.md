# 부름 시험 — "미티야, ~ 뭐로 정했었지?"

미티를 불러 기록을 묻는다. 미티는 기록(HEAD)을 근거로 1~2문장 답한다(speak answer).
설정 명령이 아닌 부름이고, 강도와 상관없이 답한다(강도 low에서도).

## 회의 설정

- title: 부름 시험
- participants: 기헌, 준영, 태은, 지호
- intensity: low
- agenda:
  1. 정리 — expected: []

## 대본

```
태은: 로고 시안 만들고 있는데 이름이 뭐였더라.
기헌: 미티야, 서비스 이름 뭐로 정했었지?
[미티 기대] speak answer — "미티"로 정했다, 10/10 회의. 근거: 이름 결정
준영: 아 맞다. 그럼 승인 방식은 기본이 뭐였죠?
지호: 밋티야, 승인 방식 기본값 뭐였어?
[미티 기대] speak answer — 팀별 설정, 기본은 누구나 한 명. 근거: 승인 방식 결정
태은: 고마워요.
```
