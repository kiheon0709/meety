# 오탐 시험 2 — 의견은 부딪치지만 확정된 결정은 없는 회의

기록(HEAD)에 결정이 없는 주제(슬라이드 색, 데모 데이터, 끼어드는 장면 수)에서 의견이 갈린다.
미티를 3인칭으로 말하는 줄("미티가 끼어드는 장면")과 "미트볼"도 있다. 미티는 조용해야 정답이다.

## 회의 설정

- title: 발표 자료 논의
- participants: 기헌, 준영, 태은, 지호
- intensity: high
- agenda:
  1. 발표 자료 — expected: []

## 대본

```
기헌: 발표 슬라이드 톤 얘기해 보자. 아직 안 정했잖아.
태은: 저는 밝은 색이 좋아요. 대학생 팀 느낌 나게요.
지호: 저는 어두운 배경이 나아요. 시연 화면이 더 잘 보여요.
준영: 데모 데이터는 우리 회의를 쓰는 게 좋을까요, 가짜 회사 회의가 좋을까요?
태은: 우리 회의가 진짜 같아서 좋을 것 같은데요.
지호: 근데 우리 회의는 너무 내부 얘기라 심사위원이 못 알아들을 수도 있어요.
준영: 미티가 끼어드는 장면을 몇 번 넣을지도 고민이에요. 너무 많으면 시끄러워 보여요.
기헌: 미트볼 집 가서 마저 얘기할까. 아직 결론은 안 내도 돼.
```

## 하면 안 되는 것 (오탐)

- 어느 줄에서든 speak·hand_raise (확정 결정이 없는 주제의 의견 충돌)
- "미티가 끼어드는 장면" 줄에 대답하기 (3인칭 언급)
- "미트볼"을 호출어로 받기
