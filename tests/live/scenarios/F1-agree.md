# 오탐 시험 1 — 결정과 맞는 말만 하는 회의

예시 스페이스 HEAD(회의 1~3 정리 결과)와 **맞는 말**만 나온다. 결정을 다시 확인하는 질문, 결정 안에서 세부를 정하는 말,
"미팅"처럼 호출어와 비슷한 일반 단어가 섞여 있다. 미티는 조용해야 정답이다(끼어들기·손들기 0).

## 회의 설정

- title: 점검 회의
- participants: 기헌, 준영, 태은, 지호
- intensity: high
- agenda:
  1. 지난 결정 점검 — expected: []

## 대본

```
기헌: 오늘은 지난번 정한 거 점검만 하자. 입구는 웹으로 가는 거 맞지?
준영: 네, 웹 중심이고 디스코드 봇은 2단계예요. 이번엔 웹 화면 다듬는 데 집중하면 돼요.
태은: 녹음은 브라우저 녹음 버튼이랑 녹취 붙여넣기 둘 다 두는 걸로 화면 그렸어요.
지호: 승인은 기본이 누구나 한 명이죠? 설정 화면에서 팀마다 바꿀 수 있게요.
기헌: 맞아. 그리고 이름은 미티로 확정이니까 로고 시안도 미티로 가면 돼.
준영: 대학생 팀플 팀이 타깃이니까 예시 화면도 팀플 회의로 채울게요.
태은: 다음 미팅은 언제 할까요? 저는 금요일 오후 좋아요.
지호: 저 금요일은 수업이라 토요일이 나아요.
기헌: 그건 단톡방에서 정하자.
```

## 하면 안 되는 것 (오탐)

- 어느 줄에서든 speak·hand_raise (모두 기존 결정과 맞는 말)
- "미팅"을 호출어로 받기
