# 능동형 2 — 여럿이 브레인스토밍 (막힐 때만 거들기)

넷이 시연 아이디어를 낸다. 말이 잘 이어질 땐 미티가 가만히, 막혀서 조용해지면 아이디어 하나.

## 회의 설정

- title: 시연 아이디어
- participants: 기헌, 준영, 태은, 지호
- intensity: high
- mode: brainstorm
- agenda:
  1. 시연 아이디어 — expected: []

## 대본

```
(침묵 5초)
기헌: 시연 아이디어 좀 내 보자. 심사위원이 바로 이해할 만한 걸로.
준영: 회의 중에 미티가 어긋난 걸 잡는 장면이 제일 세지 않아요?
태은: 맞아요, 그걸 첫 장면으로 하고 그다음에 정리 화면.
지호: 정리 화면에선 바뀐 결정이 표시되는 걸 보여 주면 좋겠어요.
기헌: 좋아. 근데 마지막 장면을 뭘로 끝내지.
준영: 음… 글쎄요.
(침묵 7초)
[미티 기대] speak suggest — 막힌 데서 아이디어 하나(기록·자료와 이어지면 더 좋음)
태은: 오 그거 괜찮다.
기헌: 그럼 그렇게 가자.
```

## 하면 안 되는 것 (오탐)

- 1~4줄(말이 잘 이어지는 중)에 먼저 꺼내기
