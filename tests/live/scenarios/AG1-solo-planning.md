# 능동형 1 — 1:1 기획 회의 (먼저 꺼내기)

기헌 혼자 미티와 발표 준비를 한다. 기헌이 말을 멈추고 생각하는 동안 미티가 스스로 할 일·빈 것·아이디어를 꺼내야 한다(10/31 기헌 결정: "대답만 하는 대화판 말고 먼저 꺼내는 팀원").
쓸모: 근거가 맞는가(기록·자료의 마감·할 일), 타이밍(침묵 중), 중복 아님. 과함: 말하는 중에 끼지 않기, 분당 횟수.

## 회의 설정

- title: 발표 준비 1:1
- participants: 기헌
- intensity: high
- agenda: []

## 대본

```
(침묵 5초)
기헌: 오늘은 발표 준비 얘기 좀 하자.
기헌: 슬라이드는 내가 만들고 있는데, 뭐부터 해야 할지 모르겠네.
(침묵 7초)
[미티 기대] speak suggest — 할 일·마감(제출일 등)이나 빈 것을 스스로 꺼냄
기헌: 아 그렇지. 그럼 시연 영상은 누가 찍지.
기헌: 음.
(침묵 7초)
[미티 기대] speak suggest — 영상 담당이 비었음을 짚거나 방법 제안
기헌: 알겠어, 일단 내가 정리해 볼게.
```

## 하면 안 되는 것 (오탐)

- 기헌이 말하는 중간(침묵 없는 곳)에 먼저 꺼내기
- 같은 말 두 번
- 기록·자료에 없는 날짜·사람
